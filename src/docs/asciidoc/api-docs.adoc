== 개요

DaPanda 서비스의 REST API 문서입니다.

=== HTTP 상태 코드

본 REST API에서 사용하는 HTTP 상태 코드는 성공일 경우 200응답, 실패일 경우 내부 규약을 따릅니다.

|===
| 상태 코드 | 용례

| `200 OK`
| 요청을 성공적으로 처리함

| `400 Bad Request`
| 잘못된 요청을 보낸 경우. 유효하지 않은 입력값, 파라미터, 비즈니스 로직 위반 등

| `401 Unauthorized`
| 인증이 필요하거나 토큰이 유효하지 않은 경우

| `403 Forbidden`
| 인증은 되었으나 해당 리소스에 대한 권한이 없는 경우

| `404 Not Found`
| 요청한 리소스가 존재하지 않음

| `409 Conflict`
| 리소스의 현재 상태와 충돌하여 요청을 완료할 수 없음 (중복 이메일, 사용자명 등)

| `500 Internal Server Error`
| 서버 내부 오류가 발생한 경우
|===

=== 오류

에러 응답이 발생했을 때, 본문에 해당 문제를 기술한 메시지가 담겨있다.

==== 에러 응답 구조

```
{
    "code": {커스텀 상태 코드}
    "message": {에러 발생 이유}
}
```

==== 에러 응답 예시

```
{
    "code": 9000,
    "message": "회원을 찾을 수 없습니다."
}
```
